🆕 New Features Added

1.  Phase imbalance alarm

Modern homes use high-power devices like EV chargers, heat pumps, and induction stoves, which can create uneven load across electrical phases. When phases become unbalanced, it can lead to:
- Reduced efficiency
- Higher strain on circuits
- Unnecessary fuse trips
- Heat buildup and equipment wear
  
The Phase Imbalance Alarm helps you detect these issues early.

📊 By exposing this as a binary alarm in Home Assistant, you get:
- Immediate alerts when imbalance is unhealthy
- Clear visual history in the dashboard
- Better insight for scheduling high-load appliances
  
This feature supports Tibber’s goal of smarter, safer, and more efficient electricity usage.

2.  15 min and 1 hour pricing interval options

Energy prices can vary significantly throughout the day. This update adds support for both hourly and quarter-hourly price intervals, 
where you can select the peicing interval of your choice on the price graph.

📈 This feature provides:
- More accurate visibility into short term price changes
- Easier identification of the lowest cost consumption periods
- Improved decision making when scheduling high power appliances
